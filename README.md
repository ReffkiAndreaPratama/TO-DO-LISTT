# Pocket — Expense Tracker

Aplikasi pencatat keuangan pribadi berbasis HTML, CSS, dan JavaScript murni.

## Fitur
- Catat pemasukan dan pengeluaran.
- Kategori transaksi berdasarkan tipe.
- Ringkasan saldo bersih, pemasukan, dan pengeluaran.
- Grafik donat pengeluaran per kategori.
- Riwayat transaksi terbaru dan tabel semua transaksi.
- Cari transaksi serta filter berdasarkan tipe dan bulan.
- Tambah, edit, dan hapus transaksi.
- Mode gelap dan terang.
- Penyimpanan otomatis menggunakan `localStorage`.
- Layout responsif.

## Menjalankan aplikasi
Ekstrak folder lalu buka `index.html` di browser modern. Tidak perlu Node.js, database, backend, maupun API key.

## Hosting gratis
Unggah file ke repository GitHub dan aktifkan GitHub Pages, atau gunakan layanan hosting statis seperti Cloudflare Pages dan Netlify.

expense-tracker/

## Privasi dan penyimpanan
Data disimpan secara lokal pada browser yang digunakan dan tidak tersinkron otomatis ke perangkat lain. Hindari memasukkan informasi keuangan rahasia. Membersihkan data browser dapat menghapus transaksi tersimpan.
